### Engineering Focus

**[DualSense-haptic-helper](https://github.com/HotspringDev/DualSense-haptic-helper)**  
A bridge for Sony DualSense features on Linux. By interfacing with PipeWire and raw HID, this project enables native haptic feedback and adaptive triggers within Proton environments. It targets the technical gap in Linux gaming infrastructure, ensuring hardware behaves as intended.

**System Architecture & Tooling**  
Ongoing development of native utilities for Linux. Focus includes ALSA/PipeWire node mapping, udev rule optimization, and debugging system-level regressions to maintain a high-performance open-source workspace.
